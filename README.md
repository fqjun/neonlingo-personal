# NeonLingo 个人版

仿 [NeonLingo](https://www.neonlingo.com/zh-CN) 的本地自用 Chrome / Edge 插件：浏览中文网页时，按你的难度和词汇量把部分中文词替换成英文单词，在语境中循序渐进地学；生词自动进生词本，用间隔重复（FSRS）复习。

## 功能

- **沉浸式替换**：只挑略高于你水平的词（i+1），专有名词、代码不动；悬停看音标、释义、原文，🔊 发音；单击单词在英文和原文之间切换，**双击单词表示「不认识」，直接加入生词本**。
- **水平与难度**：
  - 「当前外语水平」按 CEFR 分为 A1–C2 六档，每档附有国内考试的大致对应。
  - 「想学的单词难度」有三档：
    - 轻松巩固：以已掌握的词为主，用当前档位。
    - 稍有挑战（默认）：熟悉的内容里夹少量高一档的新词。
    - 更有挑战：高两档的进阶新词。
  - 替换密度按段落词数的比例计算：少 2%、中 5%、多 8%。
- **循序渐进**：
  - 悬停卡片上点「不认识」，词进入生词本（学习中）。之后在网页上会优先复用这些词，增加曝光。
  - 连续点 3 次「认识」，或复习后记忆稳定度超过 60 天，算作掌握，之后不再替换。
  - 每掌握一个词，有效词汇量 +1，选词难度自动缓慢提高。
- **划词翻译**：选中单词或短语，点「译」（或开启划词自动翻译、右键菜单），按整句语境解释。
- **查词后自动收藏**（可关闭）：查过的单词会加入单词本，并在所有网页上用单独的颜色（默认琥珀色）提示。关闭此项，不影响网页上自动替换的词通过双击、「不认识」或 ☆ 加入单词本。
- **全网高亮**：生词本里正在学的词出现在任何网页（包括英文网页）上时都会被标出，这一步在本地匹配，不调用 API。
- **生词本与复习**：搜索、筛选、例句和出处；FSRS 闪卡复习，快捷键是空格和 1–4；扩展图标上的角标显示待复习数；可以导出 CSV（能导入 Anki）或 JSON 备份。
- **多模型**：
  - Claude（官方 SDK），默认模型 Claude Opus 5.5，可以切换 Sonnet 5.5 或 Haiku 5.5。Opus 和 Sonnet 开启了服务端 fallback。
  - 任何 OpenAI 兼容接口：DeepSeek、通义千问、Kimi、智谱、OpenAI、本地 Ollama 等。
- **多电脑同步**：设置和生词本通过 Chrome 账号同步（`chrome.storage.sync`）。

## 安装

1. 首次或修改代码后构建（需要 Node 18+）：
   ```bash
   npm install
   npm run build
   ```
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），开启「开发者模式」，点「加载已解压的扩展程序」，选择本文件夹。
3. 安装后会自动打开设置页：选择模型通道，填写 API Key，点「测试连接」。
4. 打开任意中文网页即可。点击工具栏图标可以调整难度、词汇量和密度，或在当前网站关闭。

> 改了 `src/` 下的代码需要重新 `npm run build`，然后在扩展页点刷新。`content/`、`popup/`、`options/`、`vocab/` 下的文件不需要构建，刷新扩展即可。

## 在另一台电脑使用

- **插件要在每台电脑上各装一次**：已解压加载的插件不会随 Chrome 账号同步。把整个文件夹（含 `dist/`）拷过去，按上面第 2 步加载即可，那台电脑不需要 Node。
- **数据自动同步**：两台电脑登录同一个 Chrome 账号，并在同步设置中开启「扩展程序」，设置、生词本和复习进度就会自动同步。
  - `manifest.json` 里固定了 `key`，保证插件 ID 在每台电脑上都一样，同步才能对上。ID 是 `lcnggecbjcffnhbhlkoflncapghgnfkc`。
  - Chrome 同步空间约 100 KB，大约能放 900–1000 个词。超出时，较早掌握的词只保存在本机。
  - 例句和出处只保存在本机。完整备份请用设置页的「导出 JSON」。
  - API Key 默认只保存在本机。在设置页勾选「通过 Chrome 账号同步 API Key」后，另一台电脑就不用重新填写。

## 费用提示

- 每个段落的结果都会缓存在本机，刷新同一页面不会重复计费。
- 「单页最多处理字数」默认是 20000，可以在设置页调整。
- 只有滚动到可视区域附近的内容才会发给模型处理。
- 大量浏览时，可以换用 Claude Haiku 5.5 或 DeepSeek 等更便宜的模型。

## 本地 Ollama

启动 Ollama 前设置环境变量，允许扩展访问：

```powershell
setx OLLAMA_ORIGINS "chrome-extension://*"
```

然后在设置页选择「本地 Ollama」预设，并填写你已下载的模型名。

## 目录

```
manifest.json          MV3 清单
src/                   后台 service worker（esbuild 打包到 dist/background.js）
  background.js        消息路由、翻译缓存、统计、角标、同步调度
  prompts.js           选词 / 查词提示词与 JSON Schema
  vocab.js             生词本存储与 Chrome 账号同步
  fsrs.js              间隔重复算法（简化 FSRS）
  providers/           Claude（官方 SDK）与 OpenAI 兼容接口
content/               内容脚本：替换、高亮、悬停卡片、划词翻译
popup/ options/ vocab/ 工具栏弹窗、设置页、生词本与复习页
common/                共用设置常量与样式
scripts/make-icons.mjs 生成图标
```
